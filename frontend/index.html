FindIt – Campus Lost & Found Management System

A DBMS Microproject for Computer Engineering (Semester 3). Demonstrates relational design, Oracle SQL, PL/SQL stored procedures, cursors, triggers, concurrency control, and atomic transactions.

Technology Stack: • Database: Oracle Database 19c/21c/23c & PL/SQL • Backend: Java REST API (JDBC PreparedStatement) • Security: PBKDF2 / BCrypt Hashing & RBAC • Frontend: HTML5, CSS3 & ES6+ Modern Architecture
